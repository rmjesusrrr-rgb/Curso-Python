# Curso de Python - Santander Open Academy

Repositorio con los programas prácticos, apuntes, resumen y material del curso **Python** de Santander Open Academy.

---

## 📚 Estructura de Programas

1. [`01_hola_mundo.py`](01_hola_mundo.py): Primer programa con `print()`.
2. [`02_variables_y_tipos.py`](02_variables_y_tipos.py): Variables (`int`, `float`, `str`, `bool`) y conversión de tipos.
3. [`03_operadores.py`](03_operadores.py): Operadores aritméticos, relacionales y lógicos.
4. [`04_condicional_par_impar.py`](04_condicional_par_impar.py): Estructuras de control `if`, `elif`, `else`.
5. [`05_bucles_for_y_while.py`](05_bucles_for_y_while.py): Bucles `for`, `while` y acumuladores.
6. [`06_control_bucles_break_continue.py`](06_control_bucles_break_continue.py): Control de flujo con `break` y `continue`.
7. [`07_listas_y_metodos.py`](07_listas_y_metodos.py): Listas, mutabilidad y métodos como `.append()`.
8. [`08_tuplas_y_conjuntos.py`](08_tuplas_y_conjuntos.py): Inmutabilidad de tuplas y elementos únicos en conjuntos (`set`).
9. [`09_diccionarios.py`](09_diccionarios.py): Estructuras clave-valor y sus métodos.
10. [`10_funciones_y_lambdas.py`](10_funciones_y_lambdas.py): Definición de funciones, parámetros, `return`, ámbito y `lambda`.
11. [`11_manejo_excepciones.py`](11_manejo_excepciones.py): Control de errores con `try / except / else / finally` y excepciones personalizadas.
12. [`12_archivos_lectura_escritura.py`](12_archivos_lectura_escritura.py): Manejo seguro de archivos con `with open(...)`.
